# Getting help

[Français](SUPPORT.md) · English

Desktop Cat is a personal project, maintained by one person in their spare time: there is no commercial support and no
guaranteed response time.

## Before asking for help

1. Check [docs/en/TROUBLESHOOTING.md](./docs/en/TROUBLESHOOTING.md) — where the files are, how to read the log, and the
   problems already encountered (invisible cat, no gift, unreadable save file...).
2. Open the log: right-click the tray icon, then **Ouvrir le journal** ("Open the log")
   (`%APPDATA%\DesktopCat\desktopcat.log`).
3. Search the [existing issues](https://github.com/Alithiel31/cali-desktop-cat/issues), open and closed.

## Reporting a bug or requesting a feature

Open an [issue](https://github.com/Alithiel31/cali-desktop-cat/issues/new/choose) — the templates ask for the useful
context (Windows version, screen setup, last lines of the log...). The templates are in French; you are welcome to
write in English.

## Contributing

Development environment, tests, commit convention: see [CONTRIBUTING.en.md](./CONTRIBUTING.en.md).
